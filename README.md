# 기말고사 공부 플래너

2026년 2학기 기말고사(12.7–12.11) 대비 공부 계획표 웹앱입니다. 휴대폰 홈 화면에 앱처럼 설치해서 쓸 수 있습니다.

## 기능
- **오늘**: 오늘(과 내일) 할 일, 체크하면 진행률이 올라갑니다
- **전체 일정**: 날짜별 계획, 과목별로 걸러 보기
- **진행률**: 과목별 진행률, 밀린 할 일을 오늘로 옮기기
- **설정**: 과목·시험 일정 편집, 백업 내보내기/가져오기, 초기화
- 할 일은 탭해서 내용·시간·과목·날짜를 바꾸고, 순서 변경·복제·삭제할 수 있습니다
- 수정 내용은 브라우저에 자동 저장됩니다(기기마다 따로 저장)

## GitHub Pages로 올리기
1. GitHub에서 **New repository**를 만듭니다 (예: `final-planner`, Public).
2. **Add file → Upload files**를 눌러 이 폴더의 파일 5개(`index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`)와 이 README를 올리고 **Commit**합니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 두고 **Save**합니다.
4. 1–2분 뒤 `https://<내 아이디>.github.io/final-planner/` 주소로 열립니다.

## 휴대폰에 앱으로 설치
- **iPhone (Safari)**: 위 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome)**: 위 주소 열기 → ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**

## 계획 기본값 고치기
`index.html`의 `DEFAULT_DATA()` 안의 목록이 처음 계획입니다. 여기를 고치면 **설정 → 처음 계획으로 초기화** 했을 때 그 내용으로 시작합니다.
파일을 고친 뒤에는 `sw.js`의 `CACHE = 'planner-v1'` 숫자를 올려 주면 설치된 앱도 새 버전을 받습니다.

## 기기 간 옮기기
설정 → **내보내기**로 복사한 내용을 다른 기기에서 설정 → **가져오기**에 붙여넣으면 됩니다.
